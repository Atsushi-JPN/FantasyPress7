# FantasyPress7

A retro RPG-inspired child theme for the WordPress theme **GeneratePress**.
Crafted for gamers, streamers, VTubers, and retro enthusiasts who love **classic RPG menu screens** reimagined with a modern **"HD Remaster"** touch.

## Features
* **HD Remaster RPG Aesthetic**: Features rich CSS gradients and polished window styling—like a modern HD remaster of golden-era 32-bit RPG interfaces.
* **Fully Compatible with RPGPress1**: Shares the exact same functionality and structure as **FantasyPress6** (classic 8-bit/16-bit style), so you can freely switch between the two to change your site's mood.
* **Built-in Breadcrumbs**: Clean, game-styled breadcrumb navigation included.
* **Custom Share Buttons**: Integrated social sharing buttons matching the retro-modern theme.
* **Lightweight & Fast**: Built on top of GeneratePress for optimal performance.

## Requirements
* WordPress 6.0 or higher
* **GeneratePress** (Parent theme must be installed)
* PHP 8.0 or higher

## Installation

1. Go to the **[Releases]** section on the right side of this page and download the latest `FantasyPress7.zip` file. *(Note: Do not use "Download ZIP" from the green Code button, as it may cause folder structure issues.)*
2. Log in to your WordPress dashboard and go to **Appearance > Themes > Add New**.
3. Click **Upload Theme** at the top, select the `FantasyPress7.zip` file, and click **Install Now**.
4. Once installed, click **Activate**. *(Make sure GeneratePress is already installed.)*
